# Расписание занятий

Учебный проект: сервис для просмотра и управления расписанием занятий вуза.

## Запуск

```bash
cp .env.example .env   # заполнить переменные
docker compose up --build
curl http://localhost:8080/health   # должно вернуть 200
```

## Роли

| Роль | Участник | Отвечает за | Файлы |
|---|---|---|---|
| Архитектор данных | _вписать имя_ | схема таблиц, связи, тестовые данные | `schema.sql`, `seed.sql` |
| Бэкендер А | _вписать имя_ | SQL-запросы, работа с базой | `store.go`, `model.go` |
| Бэкендер Б | _вписать имя_ | хендлеры, коды ответов, валидация | `handlers.go`, `main.go` |
| Интегратор | _вписать имя_ | контракт API, curl-проверка, вёрстка | `README.md`, фронт |

> Если в команде 3 человека — роли «Архитектор данных» и «Интегратор» совмещает один участник.

## Схема данных

`groups`, `teachers`, `subjects`, `classrooms`, `lessons` — подробности в `schema.sql`.
Связи «один ко многим»: группа/преподаватель/предмет/аудитория → много занятий.
Состояние: `lessons.status` (`scheduled` / `cancelled` / `moved`).

### Объект Lesson

```json
{
  "id": 1,
  "subject_id": 3,
  "subject_name": "Базы данных",
  "teacher_id": 2,
  "teacher_name": "Иванова А. С.",
  "group_id": 1,
  "group_name": "ИВТ-21",
  "classroom_id": 5,
  "classroom_name": "412",
  "day_of_week": 2,
  "start_time": "10:00",
  "end_time": "11:30",
  "status": "scheduled",
  "created_at": "2026-09-21T09:38:37+05:00"
}
```

### Тело запроса для POST /lessons

```json
{
  "subject_id": 3,
  "teacher_id": 2,
  "group_id": 1,
  "classroom_id": 5,
  "day_of_week": 2,
  "start_time": "10:00",
  "end_time": "11:30"
}
```

### Валидация (422, если нарушено)

- `day_of_week` — от 1 до 7;
- `end_time` строго больше `start_time`;
- `subject_id`, `teacher_id`, `group_id` — существуют в базе;
- пересечение по времени для одной группы/преподавателя/аудитории в одном `day_of_week` — конфликт (решить: запрещать или предупреждать — обсудить в команде).
